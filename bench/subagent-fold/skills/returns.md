# 返品・返金スキル (returns)
- 返品可否・返金について回答する前に、必ず get_return_policy で該当カテゴリのポリシー(破損の場合は damaged)を取得し、注文情報(カテゴリ・final_sale)と配達完了日を確認する。
- 返品期限の起算日は「配達完了日」(get_shipment の delivered_at)。注文日ではない。未配達の場合は配達予定日を起点とした見込み期限として、確定は配達完了日基準であると伝える。
- 期限日は 起算日 + N日 で計算し、具体的な日付(YYYY年M月D日)で伝える。今日の日付と比較して期限内か判定する。
- ポリシー上返品不可の場合、返金を約束しない。代替案(初期不良窓口など)があれば案内する。
- 返金・交換を「確約」してよいのはポリシー上の条件をすべて満たすことが確認できた場合のみ。破損の場合は写真確認前に返金を確約しない。
